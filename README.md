# Пояснение к программе

## Код выполнения сделан в ручную с использованием SimpleJson, на версии Java 11
Сайт с которого была получена сылка на SimpleJson: "https://cliftonlabs.github.io/json-simple/"

## Вывод написан с помощью нейросети в главном классе App
Запуск происходит тоже в классе App

### Что было использовано
| Компонент | Версия | Описание |
|-----------|--------|----------|
| **Java** | 11 | Основной язык программирования |
| **Maven** | 3.8+ | Система сборки и управления зависимостями |
| **SimpleJson** | 4.0.1 | Библиотека для парсинга JSON-файлов |
